# Jogo de Adivinhação de Palavras

Projeto desenvolvido para a atividade de encerramento da disciplina de Desenvolvimento de Aplicações Web I — IFPB, Campus Campina Grande.

## Integrantes
- José Darllan da Silva Martins

## Como jogar
1. Observe a categoria e a dica apresentadas.
2. Digite uma letra no campo indicado.
3. Clique em **Tentar** ou pressione **Enter**.
4. As letras corretas serão reveladas na palavra.
5. Cada letra incorreta reduz uma tentativa.
6. Você vence quando descobrir todas as letras antes de acabar as tentativas.

Clique em **Nova partida** para jogar novamente.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Escolha aleatória entre 12 palavras.
- Exibição da palavra escondida por traços.
- Categorias e dicas para as palavras.
- Identificação de letras corretas e incorretas.
- Controle de seis tentativas.
- Exibição das letras utilizadas.
- Bloqueio de letras repetidas.
- Mensagens de vitória e derrota.
- Reinício da partida.
- Envio da tentativa pela tecla Enter.
